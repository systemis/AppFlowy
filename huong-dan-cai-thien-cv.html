2. LinkedIn & portfolio FE

  • LinkedIn URL trên CV — nhiều pipeline auto-skip nếu không có.
  • 1 trang portfolio (Next.js static cũng được): 3 case study ngắn — Seitrace UI, Connect SDK, Kinobi live preview — mỗi case: 1 screenshot, 3 bullet, link demo/GitHub nếu public.
  • Headline LinkedIn trùng hướng apply: Senior Full-Stack · React/Next.js · Real-time & Web3 UX (điều chỉnh theo JD).
  • Pin 2–3 repo hoặc npm package trên GitHub profile (@ancient8/connect, explorer UI nếu open).
Ưu tiên cao

3. Docksoft — làm rõ hoặc CV sẽ yếu so với Cavies/Ancient8

Vấn đề: “Consumer apps” không tên, không link → recruiter nghi filler.

Cần làm:

  • Liệt kê 1–2 tên app + link App Store / web.
  • Ghi rõ stack FE: React Native vs Next.js marketing site, state management (Zustand/Redux/Context), payment UI.
  • Giải thích timeline: part-time song song Cavies (đã ghi trên CV) — sẵn sàng giải thích trong phỏng vấn.
Nếu app chưa public: mô tả niche + screenshot trong portfolio (private case study) thay vì bullet chung chung.
Frontend — chi tiết từng mảng

4. Seitrace (explorer UI)

CV mới đã thêm React/Next.js, search, caching client. Còn thiếu trên giấy tờ (bạn tự bổ sung số):

  • Kiến trúc data phía client: React Query / SWR / custom cache? SSR vs CSR cho trang block/tx?
  • Table & pagination: virtual scroll (react-window/tanstack virtual) nếu có list lớn.
  • SEO & share: meta tags cho address/tx pages (quan trọng với explorer).
  • Accessibility: keyboard search, focus trap trong modal (nếu có).
Apply role “Frontend”: đưa bullet Seitrace FE lên đầu CaviesLabs; rút bớt Kafka/ClickHouse xuống 1 bullet.
Frontend

5. HeavenDash / brrr (real-time dashboard)

  • Ghi rõ thư viện chart (Recharts, ECharts, D3, TradingView lightweight?) — keyword ATS cho “data visualization”.
  • WebSocket reconnect, stale state, loading skeleton — thể hiện mature FE.
  • Nếu có: dark mode, responsive breakpoints cho trader mobile.

Bullet mẫu (chỉnh số thật):

“Built DeFi ranking dashboards in Next.js with WebSocket-driven tables; handled reconnect/backoff and skeleton states so metrics stay consistent during Kafka lag spikes.”
Frontend

6. Ancient8 Connect (SDK / design system nhẹ)

Đây là điểm FE mạnh nhất trên npm — cần tối đa hóa:

  • UMD + CSS bundle: cách partner embed (<script> vs npm).
  • Modal/wallet UX: multi-wallet, chain switch, error copy tiếng Anh rõ ràng.
  • Testing: Storybook hoặc demo app? unit test cho hooks?
  • semver, breaking changes, changelog — signal “maintainer”.
Thiếu thường gặp: không nêu bundle size / tree-shaking → thêm nếu bạn đo được (webpack-bundle-analyzer).
Frontend

7. Dojo launchpad (high-stress UX)

  • Mint flow: whitelist check → connect wallet → sign → confirm — nêu rõ state machine / disable double-click.
  • Loading & error khi RPC chậm (Solana) — recruiter Web3 rất quan tâm.
  • Partner games (Sipher, CyBall, Blast Royale) — giữ tên, là social proof.
Frontend

8. Kinobi — document editor & live preview

Story rất tốt cho role product FE. Bổ sung kỹ thuật (nếu đúng với code bạn viết):

  • Rich text: ProseMirror, Slate, Draft.js, hoặc contenteditable custom?
  • Preview <1s: debounce ms, web worker, iframe sandbox?
  • Export PDF/DOCX phía client hay server?
Đây là dự án meta cho CV hiện tại — nên 1 đoạn case study 200 từ + GIF preview trên portfolio.
Frontend

9. Green Global & Wideworks (nền tảng FE truyền thống)

  • Green Global: form phức tạp (billing), validation schema (Yup/Zod), i18n nếu có.
  • Wideworks: responsive, CMS (WordPress headless?), performance budget.
  • Giúp apply fintech/enterprise VN — đừng chỉ 1 bullet; thêm 1 bullet về a11y hoặc mobile nếu có.

11. Positioning khi apply FE vs Full-stack

  • JD Frontend/Product: tagline nhấn React/Next.js + 2 sản phẩm UI (Seitrace, Connect); summary rút Kafka xuống 1 câu.
  • JD Platform/Backend: giữ data pipeline; FE 1–2 bullet chứng minh bạn không “chỉ backend”.
  • JD Web3: Dojo + Connect lên đầu; Seitrace là infra credibility.

Tạo 2 file PDF từ cùng HTML (hoặc nhờ agent duplicate summary) — đừng gửi 1 bản cho mọi loại job.

Dài hạn

12. Vì sao ít phản hồi (ngoài nội dung CV)

  • Thị trường Web3 co — cần song song apply SaaS/fintech/product VN-SG remote.
  • Cold apply volume cao — referral + LinkedIn message ngắn hiệu quả hơn.
  • Mỗi JD: chèn 5 từ khóa từ posting vào summary + skill (không spam).
  • Cover letter 5 câu: 1 sản phẩm FE liên quan + 1 metric + lý do company.
